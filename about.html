关于「物理学全景图」

一张可交互、可探索的物理学三百年演化图谱——写给所有对「宇宙如何被理解」感到好奇的人。

项目定位

本项目面向高中生、大学生、科普爱好者与教师，把物理学从牛顿力学到标准模型、再到量子引力的演化路径，可视化为一张可缩放、可深入的全景图谱。我们试图在「严谨准确」与「轻松可读」之间取得平衡：复杂的概念被拆解成清晰的小节，而非堆砌公式。

内容来源与可信度

  • 节点正文与术语释义参考标准物理教材与权威科普资料，并经人工整理与互校；
  • 诺贝尔物理学奖数据（1901–2025）取自诺贝尔奖官方公开记录，人名与获奖理由保留英文原文以符合引用惯例；
  • 人物肖像优先使用公有领域图像或维基共享资源，缺图时以淡金首字占位符优雅回退；
  • 内容持续修订中，个别细节可能存在误差，欢迎指出。

参与方式

这是一个开放的公共教育资源。如果你发现错误、希望补充内容，或想参与翻译与建设，欢迎通过以下渠道：

  • 在项目的 GitHub 仓库提交 Issue 或 Pull Request；
  • 通过站内反馈入口提出建议。

致谢
